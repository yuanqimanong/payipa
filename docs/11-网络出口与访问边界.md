# 11 · 网络出口与访问边界

状态：**已定案**（2026-07-10）

## 1. 目标

payipa 的网络层只为已获授权的数据访问提供稳定、可审计的连接。访问许可由数据源记录决定，网络路径不能扩大许可范围。

系统遵循以下约束：

1. 网络出口由部署环境统一配置，应用、任务、规则和 agent 不选择或切换出口。
2. 数据源必须记录访问依据类型、依据引用和确认时间，未确认的数据源不能建批、调度或派发。
3. 认证失败、授权拒绝或法律限制响应会暂停整个数据源，未派发请求立即终止，其他在途任务收到取消通知。
4. 恢复只能通过人工访问复核，复核结果写入审计日志。
5. HTTP 与浏览器引擎均保持 TLS 校验，并遵守服务条款、API 文档、`robots.txt` 和数据源速率限制。

## 2. 部署职责

网络管理员可以在主机、容器平台或企业网关层配置固定的 `HTTP_PROXY` / `HTTPS_PROXY`、域名白名单和出口审计。此配置属于部署基础设施，不进入数据源规则，也不由运行时动态修改。

应用侧只记录连接结果、耗时和标准 HTTP 状态，不保存网络供应商凭证，不维护路由池，也不根据目标响应自动改变网络路径。

## 3. 访问状态

数据源包含以下状态字段：

| 字段 | 含义 |
|---|---|
| `access_basis` | `owned`、`contracted` 或 `public_policy` |
| `access_reference` | 合同编号、授权记录、API 文档或公开政策链接 |
| `access_confirmed_at` | 最近一次人工确认时间 |
| `paused_at` | 暂停时间；为空表示当前未暂停 |
| `pause_reason` | 暂停原因，供复核人员判断 |

新建数据源时必须填写访问依据并勾选确认。既有数据源缺少确认记录时保持不可运行状态。

## 4. 暂停与恢复

agent 收到 HTTP 401、403 或 451 后，不解析响应正文，也不归档该响应，并向主控回报 `ACCESS_PAUSED`。主控随后：

1. 标记数据源为暂停；
2. 将同源尚未派发的请求置为访问暂停；
3. 取消同源其他在途任务；
4. 阻止定时调度、批次创建和后续派发；
5. 等待具备 `sources.write` 权限的人员提交访问复核。

复核接口为 `POST /api/sources/{uuid}/access-review`。批准时更新访问依据并恢复调度；未批准时继续暂停。两种结果都写入 `audit_log`。

## 5. 实现边界

- `payipa.crawl.run`：授权校验、暂停、复核、调度过滤。
- `pyp_agent.conn`：识别明确的访问拒绝状态，在解析和归档前停止。
- `pyp_server.routers.api`：人工访问复核接口。
- `pyp_server.routers.ws`：整源暂停并取消其他在途任务。
- `pyp_agent.fetch`：标准 niquests / Playwright；网络路径只继承部署环境。

原有应用内动态网络路由设计已撤下，不再属于产品能力。
