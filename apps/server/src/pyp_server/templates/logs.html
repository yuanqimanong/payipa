日志查看

运行时日志与审计日志的定位说明。

payipa 分两类日志：

  • 运行时日志（structlog）：主控与各 agent 进程的结构化日志，输出到进程 stdout （容器部署经 docker logs 或日志采集器汇聚），带 task_id / batch_id / attempt_id 关联标识贯穿。当前不落库、不在此页聚合展示。
  • 操作审计日志：RBAC 敏感操作、访问复核、推送等已落 audit_log 表， 可在 操作日志 页查看。

运行时日志的页面化聚合（采集器 + 检索）属部署基础设施能力，随生产日志栈接入，不在应用内实现。
