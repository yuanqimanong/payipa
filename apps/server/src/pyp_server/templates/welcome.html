接入第一个采集节点

采集由独立的节点（agent）执行。在要跑采集的机器上任选一种方式启动（首次接入用 join token，之后节点自动换发长期凭证）：

uv run pyp-agent join --server {{ server_url }} --token {{ join_token or "" }} --state-dir ~/.pyp-agent
docker compose -f deploy/docker-compose.agents.yml up -d

说明：--server 请改为节点可达的主控地址（当前页面地址是 {{ server_url }}）； {% if join_token %}开发环境 join token 为 {{ join_token }}；{% else %}join token 从部署环境变量 PYP_SERVER_AGENT_JOIN_TOKEN 获取；{% endif %} 节点身份保存在 --state-dir 目录（容器请挂持久卷，重建不换身份）。

等待节点接入…（每 3 秒自动检测）
